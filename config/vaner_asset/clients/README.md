# Clientes VANER ASSET

Cada cliente es un tenant de la misma plataforma. No se deben duplicar carpetas de codigo, bases de datos dentro del repositorio ni archivos `.env`.

Los archivos `*.example.json` contienen solamente metadatos no sensibles. Las credenciales, dominios reales, integraciones y secretos permanecen fuera de Git.

Estructura inicial:

- Cliente 1
- Cliente 2
- Cliente 3
- Cliente VANER

Cada alta real debe recibir un identificador estable, nombre comercial, slug, estado y modulos habilitados.
