# Alta de un cliente VANER ASSET

1. Crear la empresa tenant y sus sedes.
2. Crear usuarios y asignar roles minimos.
3. Configurar identidad visual y datos de soporte.
4. Definir modulos habilitados.
5. Configurar almacenamiento, correo e integraciones.
6. Importar inventario autorizado o iniciar vacio.
7. Ejecutar pruebas de aislamiento, permisos y reportes.
8. Registrar fecha, responsable y version desplegada.

Nunca copie bases de datos, evidencias, usuarios, secretos o archivos desde SGAHolding hacia un nuevo cliente.
