# VANER SOFTWARE

VANER SOFTWARE es la marca propietaria del portafolio. VANER ASSET es el producto especializado en inventarios, activos y mantenimiento.

```text
VANER SOFTWARE
└── VANER ASSET
    ├── Cliente 1
    ├── Cliente 2
    ├── Cliente 3
    └── Cliente VANER
```

La estructura representa tenants y no copias del codigo. Todos los clientes comparten la misma aplicacion versionada y operan con aislamiento de datos y permisos.
